# Cities — аддон для Minecraft Bedrock (телефон, Windows, консоли)

Версия аддона мода «Cities» для Bedrock Edition. Деревни растут в посёлки, города и столицы, строят здания в стиле
своей культуры и перестраиваются с каждой новой эпохой. Это отдельная программа, не порт мода для ПК:
в Bedrock нет многого из Java, поэтому часть механик проще. Этап 1 — ядро.

## Установка на телефон
1. Скачайте `cities.mcaddon`: GitHub → вкладка **Actions** → запуск **Build Bedrock add-on** с зелёной галочкой →
   внизу **Artifacts** → `cities-bedrock-mcaddon` (скачается zip, внутри `cities.mcaddon`).
2. Откройте файл `cities.mcaddon` — Minecraft запустится и сам импортирует оба пакета.
3. Создайте мир (или откройте настройки существующего) → **Наборы параметров поведения** → включите **Cities (behavior)**.
   Пакет ресурсов подключится сам. Нужен Minecraft 1.21 или новее.
4. Если аддон не заработал, в настройках мира включите **Бета-API** в разделе «Экспериментальные функции».

## Как играть
- При первом входе вы получите **Книгу города** (рецепт: книга + изумруд). Нажмите ею (использовать предмет),
  чтобы открыть меню города, в котором стоите.
- Деревня становится городом сама, когда вы подходите к ней (нужно 3+ жителя). Или основайте город через книгу.
- Город раз в минуту считает жителей, ест, добывает материалы и богатство, выбирает, что строить, и строит
  блок за блоком: сам вырубает деревья, выравнивает землю, подсыпает ямы, прокладывает тропинку к центру.
- Помогайте: жертвуйте предметы через книгу (еда → еда, изумруды → богатство, блоки → материалы, бревно = 4),
  кладите вещи в сундуки склада, выполняйте задания на доске (награда — изумруды из казны).
- Уровни: хутор → деревня → посёлок → городок → город → крупный город → столица. Что нужно для следующего —
  в книге.
- Эпохи: основание → железный век → средневековье → Возрождение → индустриальная → новейшая. С новой эпохой
  старые здания постепенно перестраиваются в новом стиле.

## Культуры
Культура определяется по тому, из чего построена деревня:

| Деревня | Культура | Архитектура |
|---|---|---|
| равнинная | Германцы | солома → фахверк под красной черепицей → кирпич → бетон |
| пустынная | Арабы | глина, плоские крыши, купола, мечеть с минаретом |
| таёжная | Русь | бревенчатые избы с наличниками, луковичные главы |
| снежная | Скандинавы | тёмные дома, потом красные с белыми углами |
| саванная | Сахель | глина и солома, глиняная мечеть с жердями |
| вишнёвая роща | Японцы | белые стены, тёмные балки, пагода |
| джунгли | Майя | ступенчатые крыши, пирамида |
| прочие | Британцы | коттеджи, тюдор, кирпич |

## Проверка
В одиночной игре в книге есть кнопка «Проверка»: перепись сейчас, +1000 материалов, следующий уровень,
следующая эпоха, построить любое здание, удалить город. В сетевой игре она видна игрокам с тегом
`cities_admin` (`/tag @s add cities_admin`).
