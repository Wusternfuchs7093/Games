# Cities — мод на города для Minecraft (NeoForge 1.21.1)

Некоторые деревни со временем вырастают в посёлки, города и столицы.
Полный список задуманных механик — в [MECHANICS.md](MECHANICS.md).

## Что уже есть (этап 1 — ядро)

- **Обнаружение деревень.** Колокол с кроватями рядом в радиусе 96 блоков от игрока становится поселением. Название генерируется по культуре биома.
- **7 уровней.** Хутор → Деревня → Посёлок → Городок → Город → Крупный город → Столица. Поселение растёт, когда выполнены требования, и приходит в упадок, если теряет жителей. Если жителей не осталось совсем, оно становится заброшенным.
- **Скрытый потенциал.** Вода рядом, ровный рельеф и биом определяют, до какого уровня может вырасти поселение.
- **Территория по чанкам.** Растёт вместе с уровнем, соседние поселения не пересекаются.
- **Перепись раз в минуту:** взрослые, дети, кровати, рабочие места, занятые, фермеры и рыбаки, железные големы.
- **Экономика.** Фермеры и рыбаки производят еду, все жители её едят, каждый занятый житель приносит богатство.
- **Счастье.** Зависит от жилья, работы, еды, охраны (големов), рейдов и убийств жителей.
- **Миграция.** В процветающее поселение со свободными кроватями приходят новые жители, из несчастного уходят.
- **Репутация игрока** в каждом поселении: от «Врага» до «Героя». Убийство жителя её снижает, пожертвования повышают.
- **Летопись** событий каждого поселения.
- **Заголовок при входе в поселение**, сообщения о росте и упадке со звоном колокола.
- Перевод на русский и английский.

## Этап 2 — строительство

- **Планировщик города.** Каждую перепись решает, что строить: дом, если кроватей не хватает; ферму, если мало еды; склад, колодец, ратушу, рынок, башни, если они нужны для следующего уровня; мастерские под новые профессии; фонари для красоты.
- **Подбор места.** Ровная (перепад до 3 блоков) естественная земля на своей территории. Не на полях, дорогах, деревьях и не вплотную к другим зданиям. Дверь смотрит в сторону центра.
- **9 типов зданий** в стиле биома (равнины, пустыня, саванна, снега, тайга): дом (на 2 или 3 кровати), ферма 9×9 с поливом и культурой, склад с 4 сундуками, мастерская с двумя рабочими местами (12 вариантов профессий), колодец, рынок с навесом, ратуша с кафедрой и колоколом, сторожевая башня с лестницей и площадкой, фонарь.
- **Строитель — настоящий житель.** Предпочитается безработный. Идёт к стройке, держит в руках ставящийся блок, машет рукой, слышен звук. Ночью спит. Если долго не может дойти, телепортируется к стройке.
- **Порядок стройки:** расчистка участка сверху вниз → фундамент → стены снизу вверх → двери, кровати, освещение, посевы → дорога от двери к центру (тропа, а с уровня «Городок» — мощёная).
- **Стройматериалы.** Каждый блок стоит 1 материал. Материалы добывают жители: занятые по 1, безработные по 2 за перепись. Брёвна дают 4, любые блоки по 1 через `/city donate` или склад. Без материалов стройка ждёт.
- **Склад.** Всё, что положено в сундуки склада, при переписи забирается в запасы города (еда, материалы, богатство).
- **Здания влияют на жизнь:** новые кровати → иммиграция, рабочие места → профессии, башни, рынки и колодец повышают счастье.
- **Уровни теперь требуют зданий:** Посёлку — склад и колодец, Городку — ратуша и рынок, Городу — 2 рынка и 2 башни, и так далее.
- Строительство переживает перезагрузку мира: при загрузке стройка продолжается с того места, где остановилась.

## Этап 3 — оборона

- **Стражники.** Новое существо — рыцарь в доспехах (своя текстура). Патрулирует территорию, бьёт монстров (кроме криперов) и разбойников. Бросается на тех, кто напал на жителя. Нападает на игроков с репутацией «Враг». Вне боя восстанавливает здоровье, не исчезает.
- **Найм стражи.** Город сам нанимает по одному стражнику за перепись: 48 богатства за найм, 1 за перепись жалованья каждому. Сколько нужно: Деревня — 1, Посёлок — 2, Городок — 4, Город — 6, Крупный город — 8, Столица — 12, плюс по одному на каждую сторожевую башню.
- **Снаряжение по уровню города:** кожа и каменный меч → кольчуга → железо и железный меч → железо со щитом. Когда город вырастает, стражу переодевают.
- **Городская стена.** Строится начиная с Городка. Кольцо по краю территории повторяет рельеф. Ворота шириной 3 блока по сторонам света, проходы там, где дороги, вода, поля и дома. У Городка частокол из брёвен высотой 3, у Города и выше — каменная стена высотой 4. Когда территория растёт, строится вторая, внешняя стена. Городу нужна 1 стена, Крупному городу — 2.
- **Набеги.** Ночью, если в поселении есть игрок, с шансом 1% за уровень на каждую перепись (раз в 3 дня максимум). Отряд собирается за границей территории и идёт к центру. Размер растёт с городом: 2 + 2 за уровень разбойников и поборников, а у Крупного города и Столицы ещё и разоритель. Звучит рог набега, на экране появляется заголовок.
  - **Отбились** → +10 счастья, запись в летописи, +3 репутации за каждого убитого разбойника.
  - **Не отбились за 5 минут** → город разграблен: теряет четверть еды, материалов и богатства, −15 счастья.
- **Ударил жителя** → −2 репутации, на тебя бросается стража поблизости.
- Стража добавляет счастья (+3 за каждого, до +15).

## Этап 4 — торговля и дипломатия

- **Караваны.** Если у города есть склад или рынок и излишек еды или материалов, он отправляет караван в город, которому этого не хватает (в пределах 1024 блоков).
  - Каждый рынок позволяет держать в пути ещё один караван и увеличивает груз.
  - Время в пути зависит от расстояния.
  - Покупатель платит богатством по своей цене.
- **Динамические цены.** Цена единицы = √(сколько нужно / сколько есть), от 0.25 до 4 богатства. Дефицит дорожает, избыток дешевеет.
- **Грабежи.** Караван грабят с шансом 15%. Каждый стражник отправителя снижает шанс на 3%, но не ниже 2%.
- **Прибытие.** Если город-получатель загружен, со стороны отправителя приходит странствующий торговец с двумя ламами. С ним можно торговать, он погуляет по городу и уйдёт.
- **Цены у жителей зависят от репутации:** Герой −3 изумруда, Почётный гость −2, Друг −1, Нежеланный гость +2. С «Врагом» жители не торгуют вовсе.
- **Дипломатия.** Отношения от −100 до 100: Вражда → Соперничество → Нейтралитет → Дружба → Союз. Каждую перепись они смещаются к «естественному отношению»:
  - одна культура (стиль биома) — +20, разные — −5;
  - близкие (до 320 блоков) города похожего размера от Посёлка и выше становятся соперниками (−35);
  - каждый успешный караван добавляет +3.
- **Последствия отношений:**
  - при Соперничестве и Вражде торговли нет;
  - враждебные соседи подкупают разбойников: шанс набега умножается на (1 + число врагов);
  - союзники при набеге присылают по стражнику (до 3), стражник остаётся в городе.
- Смена отношений объявляется в чате и записывается в летописи обоих городов.

## Команды

| Команда | Кто | Что делает |
|---|---|---|
| `/city list` | все | список известных поселений |
| `/city info [название]` | все | состояние и требования к следующему уровню |
| `/city history [название]` | все | летопись |
| `/city buildings [название]` | все | список зданий поселения |
| `/city trade [название]` | все | цены, запасы и караваны в пути |
| `/city relations [название]` | все | отношения с соседями |
| `/city donate` | все | отдать предмет из руки: еда → еда, блоки → материалы (бревно = 4), остальное → богатство (изумруд = 9) |
| `/city admin create [название]` | оп | основать поселение здесь |
| `/city admin rename <название>` | оп | переименовать |
| `/city admin setlevel <уровень>` | оп | задать уровень |
| `/city admin census` | оп | провести перепись немедленно |
| `/city admin build <здание>` | оп | начать стройку указанного здания |
| `/city admin cancelbuild` | оп | отменить текущую стройку |
| `/city admin siege` | оп | начать набег на поселение немедленно |
| `/city admin hireguard` | оп | нанять стражника бесплатно |
| `/city admin relation <число> <название>` | оп | задать отношения с другим поселением |
| `/city admin remove` | оп | удалить поселение |
| `/city admin tp <название>` | оп | телепорт |

Настройки лежат в `world/serverconfig/cities-server.toml`: интервалы, радиусы, множитель населения, шанс иммиграции, `ignorePotential`, скорость стройки `buildIntervalTicks`, бесплатная стройка `freeConstruction`, стража `guardsEnabled`, набеги `siegesEnabled` и их шанс `siegeChancePerTier`, торговля `trade.enabled` и шанс грабежа `robberyChance`.

## Сборка и запуск

Нужна Java 21.

```
./gradlew runClient   # запустить игру с модом
./gradlew build       # собрать jar в build/libs/
```

При каждом пуше GitHub Actions собирает jar. Его можно скачать во вкладке Actions, раздел Artifacts.
